## 8️⃣ 수정 (옵션 방식) — `[요구 4.7]`

먼저 고칠 거래를 **id로 바로 확인해요.** (6단계 목록은 최신 5건만 보여서 TX-000005가 안 나와요)
`--id`는 `list`와 `search`에 추가한 옵션으로, **그 id의 거래 1건만** 보여줘요. 없는 id면 `[오류] 없는 데이터입니다`가 나와요.

```bash
python3 -m budget_app list --id TX-000005
```

```
ID        | 날짜       | 타입    | 카테고리 |  금액 | 메모   | 태그
----------+------------+---------+----------+-------+--------+-----
TX-000005 | 2026-09-10 | expense | food     | 42000 | 장보기 | mart
```

찾은 id로 금액만 고쳐요.

```bash
python3 -m budget_app update --id TX-000005 --amount 48000
```

```
[수정 완료] id=TX-000005
ID        | 날짜       | 타입    | 카테고리 |  금액 | 메모   | 태그
----------+------------+---------+----------+-------+--------+-----
TX-000005 | 2026-09-10 | expense | food     | 48000 | 장보기 | mart
```

- 🎯 `list --id`로 고칠 거래를 확인한 뒤, 장보기 금액을 **42,000 → 48,000**으로 고쳐요. **준 옵션만** 바뀌어요.
- ⚙️ **임시 파일에 전부 쓴 뒤 `os.replace()`로 한 번에 교체** (원자적 저장)
- 💡 미션 요구: update 방식 **고정**(우리는 **옵션 방식**) + 파일 수정 시 **안정성 고려**
