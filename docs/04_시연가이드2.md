# 🎬 시연 가이드 — 용돈 기입장이 미션 요구대로 동작하는지 보여주기

> 각 칸은 **무엇을 할지 한 줄 + 명령어**예요. 명령어를 **복사 → 터미널에 붙여넣기**만 하면 돼요.

## 0. 준비

처음 쓰는 상태로 만들어요.

```bash
rm -rf data data2 export.csv
```

## 1. add/list/search/summary/export/import/update/delete가 요구사항대로 동작하는가?

### ① add — 거래 추가

명령을 붙여넣으면 질문이 하나씩 나와요. 아래 값을 **순서대로** 입력하고 엔터를 눌러요. (3번 반복)

**1번째 — 월급**

```bash
python3 -m budget_app add
```

```
날짜(YYYY-MM-DD): 2026-09-01
타입(income/expense): income
카테고리: salary
금액(양수): 3000000
메모(선택): 9월 월급
태그(쉼표로 구분, 없으면 엔터): (그냥 엔터)
[저장 완료] id=TX-000001
```

**2번째 — 친구 저녁**

```bash
python3 -m budget_app add
```

```
날짜(YYYY-MM-DD): 2026-09-18
타입(income/expense): expense
카테고리: food
금액(양수): 200000
메모(선택): 친구 저녁
태그(쉼표로 구분, 없으면 엔터): meal,friend
[저장 완료] id=TX-000002
```

**3번째 — 택시**

```bash
python3 -m budget_app add
```

```
날짜(YYYY-MM-DD): 2026-09-22
타입(income/expense): expense
카테고리: transport
금액(양수): 15000
메모(선택): 택시
태그(쉼표로 구분, 없으면 엔터): (그냥 엔터)
[저장 완료] id=TX-000003
```

### ② list — 목록 보기

최근 거래부터 보여줘요.

```bash
python3 -m budget_app list --limit 5
```

### ③ search — 검색

9월에 food로 쓴 지출 중, 메모에 "저녁"이 있고 태그가 friend인 거래(친구 저녁)를 찾아요.

```bash
python3 -m budget_app search --from 2026-09-01 --to 2026-09-30 --category food --type expense --q 저녁 --tag friend
```

### ④ update — 수정

친구 저녁 금액을 200000 → 250000으로 고쳐요.

```bash
python3 -m budget_app update --id TX-000002 --amount 250000
```

### ⑤ delete — 삭제

택시 거래를 지워요.

```bash
python3 -m budget_app delete --id TX-000003
```

### ⑥ summary — 월별 요약

9월의 수입 · 지출 · 잔액 · 많이 쓴 곳 TOP 3를 보여줘요.

```bash
python3 -m budget_app summary --month 2026-09 --top 3
```

거래가 없는 10월은 "데이터 없음"이 나와요.

```bash
python3 -m budget_app summary --month 2026-10
```

### ⑦ export — CSV로 내보내기

9월 거래를 엑셀로 열 수 있는 CSV 파일로 저장해요.

```bash
python3 -m budget_app export --out export.csv --month 2026-09
```

### ⑧ import — CSV 가져오기

방금 만든 CSV를 새 가계부(`data2`)로 가져와요.

```bash
python3 -m budget_app import --from export.csv --data-dir data2
```

## 3. category add/list/remove가 정상 동작하는가? (삭제 시 사용 중인 카테고리 처리 포함)

### ① category add — 카테고리 추가

기본 카테고리 5개(food, transport, rent, salary, etc)에 **취미(hobby)** 카테고리를 새로 추가해요.

```bash
python3 -m budget_app category add --name hobby
```

### ② category list — 목록 보기

기본 5개 + 방금 추가한 hobby까지 6개가 보여요.

```bash
python3 -m budget_app category list
```

### ③ category remove — 삭제

안 쓰는 hobby는 지워져요.

```bash
python3 -m budget_app category remove --name hobby
```

거래가 쓰고 있는 food는 **지우지 못하게 막아요.**

```bash
python3 -m budget_app category remove --name food
```

## 5. import/export가 명시된 CSV 스키마(UTF-8, 헤더, 컬럼)로 동작하는가?

> **CSV 스키마** = CSV 파일을 쓰는 **약속된 모양**이에요. 미션이 정한 약속은 3가지예요.
> - **UTF-8**: 한글이 깨지지 않는 글자 형식
> - **헤더**: 첫 줄에 컬럼 이름이 있음
> - **컬럼**: `date,type,category,amount,memo,tags` 6개, 이 순서
>
> 내보낸 파일(export)이 이 모양인지 보고, 가져올 때(import)도 이 모양으로 읽는지 확인해요.

### ① 헤더 · 컬럼 확인

첫 줄에 컬럼 이름 6개(`date,type,category,amount,memo,tags`)가 있어요.

```bash
head -2 export.csv
```

### ② UTF-8 확인

글자 형식이 UTF-8이에요. (`charset=utf-8`)

```bash
file -I export.csv
```

### ③ 틀린 줄이 섞인 CSV 가져오기

정상 줄만 가져오고, 틀린 줄은 몇 번째 줄이 왜 틀렸는지 알려줘요.

```bash
python3 -m budget_app import --from samples/import_broken.csv --data-dir data2
```

결과

```
[완료] imported=2, skipped=4
  - 건너뜀: 3번째 줄: 날짜 형식이 올바르지 않습니다 (YYYY-MM-DD).
  - 건너뜀: 4번째 줄: 금액은 0보다 커야 합니다 (양수).
  - 건너뜀: 5번째 줄: 허용되지 않은 타입입니다: spend
  - 건너뜀: 6번째 줄: 등록되지 않은 카테고리입니다: shopping
```

| 줄 | 왜 틀렸나 |
| --- | --- |
| 3번째 | 날짜는 실제 있는 날짜만 쓸 수 있는데, **`2024-02-30`**(2월 30일은 없음)이라서 오류 |
| 4번째 | 금액은 0보다 큰 숫자만 쓸 수 있는데, **`-5000`**(마이너스)이라서 오류 |
| 5번째 | 타입은 **`income`(수입)**, **`expense`(지출)**만 쓸 수 있는데, **`spend`**라서 오류 |
| 6번째 | 카테고리는 등록된 것(food, transport, rent, salary, etc)만 쓸 수 있는데, **`shopping`**이라서 오류 |

정상인 2줄(월급, 버스)만 가져오고, 틀린 4줄은 건너뛰었어요.

## 6. 잘못된 입력/파일 오류에서 스택트레이스 없이 오류 메시지와 해결 힌트를 출력하는가?

영어 오류 화면 없이 **`[오류]` 이유 + `[힌트]` 해결 방법**만 나와요.

### ① 잘못된 입력 — 없는 달 (13월)

```bash
python3 -m budget_app summary --month 2026-13
```

### ② 잘못된 입력 — 마이너스 금액

```bash
python3 -m budget_app update --id TX-000001 --amount -500
```

### ③ 파일 오류 — 없는 파일

```bash
python3 -m budget_app import --from 없는파일.csv
```

## 7. 오류 상황에서 종료 코드가 0이 아님을 확인할 수 있는가?

맨 끝 숫자가 **종료 코드**예요. 정상은 0, 오류는 0이 아닌 숫자예요.

### ① 정상 → 0

```bash
python3 -m budget_app list --limit 1; echo "종료 코드: $?"
```

명령 2개를 이어 붙인 거예요. `;` = "그다음에"

| 조각 | 뜻 |
| --- | --- |
| `python3 -m budget_app list --limit 1` | 최근 거래 1건 보여 줘 (정상으로 끝나는 명령) |
| `;` | 그다음에 |
| `echo` | 뒤에 쓴 글자를 화면에 출력 |
| `$?` | **바로 앞 명령의 종료 코드**가 들어가는 자리 |

**종료 코드** = 프로그램이 끝나면서 남기는 숫자 성적표 → **0** = 정상 ✅ / **0이 아닌 숫자(1, 2…)** = 오류 ❌

결과

```
TX-000002 | 2026-09-18 | expense | food | 250000 | 친구 저녁 | meal,friend
종료 코드: 0
```

### ② 오류 → 1

없는 번호(TX-999999)를 지우려고 하면 오류가 나요.

```bash
python3 -m budget_app delete --id TX-999999; echo "종료 코드: $?"
```

결과

```
[오류] 없는 데이터입니다: id=TX-999999
[힌트] list 또는 search 로 id를 확인하세요. (예: TX-000001)
종료 코드: 1
```

정상(0)과 오류(1)를 나란히 보여 줘서 **오류일 때 종료 코드가 0이 아님**을 확인해요.
