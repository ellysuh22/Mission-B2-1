# 실행 가이드 — 필수 기능 한 번씩 체험하기

미션의 **필수 요구사항을 한 번씩만** 실행해 보는 가이드입니다. 위에서부터 순서대로 따라 하면 돼요.

- 걸리는 시간: 약 10분
- 아래 "예상 결과"는 실제로 실행해서 확인한 출력이에요. (`[안내]`, 시간 같은 일부만 다를 수 있음)
- 명령은 `python3`로 적었어요. (macOS 기준. `python`이 되는 환경이면 `python`도 괜찮아요)

## 한눈에 보기

| 단계 | 체험하는 기능 | 미션 요구사항 |
| --- | --- | --- |
| 1 | 도움말 `--help` | 4.1 |
| 2 | 첫 실행(자동 생성) + 카테고리 목록·추가 | 4.4, 4.11 |
| 3 | CSV 가져오기 (정상 / 깨진 행 섞임) | 4.12 |
| 4 | 거래 추가 (대화형, 틀리면 다시 묻기) | 4.3, 4.5 |
| 5 | 목록 (최신순, `--limit`) | 4.6 |
| 6 | 검색 (기간·카테고리·타입·키워드·태그) | 4.8 |
| 7 | 예산 설정·조회 + 월별 요약 | 4.9, 4.10 |
| 8 | 수정 / 삭제 / 없는 id | 4.7 |
| 9 | 카테고리 삭제 (사용 중이면 막기) | 4.11 |
| 10 | CSV 내보내기 | 4.12 |
| 11 | 오류 메시지 + 종료 코드 | 4.14 |
| 12 | 재실행 후 데이터 유지 + 저장 파일 + 실행 로그 | 4.4, 4.13 |

## 0. 준비

1. VS Code에서 터미널을 엽니다: 메뉴 **Terminal → New Terminal** (단축키 `Ctrl + ``)
2. 프로젝트 폴더(`B2-1`)에 있는지 확인합니다. `ls`를 입력했을 때 `budget_app`, `samples`가 보이면 맞아요.
   ```bash
   ls
   ```
3. **`data` 폴더가 없어야** 처음 상태로 시작할 수 있어요. 이미 있다면 지우고 시작합니다.
   ```bash
   rm -rf data export.csv
   ```

## 1. 도움말 보기 — [요구 4.1]

- [ ] 실행

```bash
python3 -m budget_app --help
```

**예상 결과** (앞부분)
```
usage: python -m budget_app [--help] <command> ...

나만의 용돈 기입장 — 콘솔 가계부

positional arguments:
  <command>
    add      거래 추가 (대화형 입력)
    list     거래 목록 (최신순)
    ...
```

> 포인트: `python3 -m budget_app add --help`처럼 **모든 명령**에 `--help`가 있어요. 옵션은 전부 `--` 표기예요.

## 3. CSV로 거래 한꺼번에 가져오기 — [요구 4.12]

- [ ] 정상 파일 가져오기

```bash
python3 -m budget_app import --from samples/import_ok.csv
```

**예상 결과**
```
[완료] imported=5, skipped=0
```

- [ ] 깨진 행이 섞인 파일 가져오기

```bash
python3 -m budget_app import --from samples/import_broken.csv
```

**예상 결과**
```
[완료] imported=2, skipped=4
  - 건너뜀: 3번째 줄: 날짜 형식이 올바르지 않습니다 (YYYY-MM-DD).
  - 건너뜀: 4번째 줄: 금액은 0보다 커야 합니다 (양수).
  - 건너뜀: 5번째 줄: 허용되지 않은 타입입니다: spend
```

> 포인트: 정상 행만 등록하고, 건너뛴 행은 **몇 번째 줄인지와 이유**를 알려줘요. 지금까지 거래는 7건(TX-000001 ~ TX-000007)이에요.

## 4. 거래 추가 (대화형) — [요구 4.3, 4.5]

- [ ] 실행 후, 아래 **입력할 값**을 차례대로 넣습니다. 첫 날짜는 **일부러 틀리게** 넣어요.

```bash
python3 -m budget_app add
```

| 질문 | 입력할 값 |
| --- | --- |
| 날짜 (1번째) | `2024-13-40` ← 일부러 틀림 |
| 날짜 (다시) | `2024-01-20` |
| 타입 | `expense` |
| 카테고리 | `food` |
| 금액 | `30000` |
| 메모 | `친구 저녁` |
| 태그 | `meal,friend` |

**예상 결과**
```
날짜(YYYY-MM-DD): 2024-13-40
[오류] 날짜 형식이 올바르지 않습니다 (YYYY-MM-DD).
[힌트] 예: 2024-01-15
날짜(YYYY-MM-DD): 2024-01-20
타입(income/expense): expense
카테고리: food
금액(양수): 30000
메모(선택): 친구 저녁
태그(쉼표로 구분, 없으면 엔터): meal,friend
[저장 완료] id=TX-000008
```

> 포인트: 틀리면 **그 항목만 다시** 물어요. 타입에 `spend`, 카테고리에 `shopping`, 금액에 `-500`을 넣어도 같은 방식으로 다시 물어요.

## 8. 수정 / 삭제 — [요구 4.7]

- [ ] 수정 (옵션 방식: 바꿀 항목만)

```bash
python3 -m budget_app update --id TX-000008 --amount 25000 --memo "친구 점심"
```

**예상 결과**
```
[수정 완료] id=TX-000008
ID        | 날짜       | 타입    | 카테고리 |  금액 | 메모      | 태그
----------+------------+---------+----------+-------+-----------+------------
TX-000008 | 2024-01-20 | expense | food     | 25000 | 친구 점심 | meal,friend
```

- [ ] 삭제

```bash
python3 -m budget_app delete --id TX-000008
```

**예상 결과**
```
[삭제 완료] id=TX-000008
```

- [ ] 같은 id를 한 번 더 삭제 (없는 데이터)

```bash
python3 -m budget_app delete --id TX-000008
```

**예상 결과**
```
[오류] 없는 데이터입니다: id=TX-000008
[힌트] list 또는 search 로 id를 확인하세요. (예: TX-000001)
```

> 포인트: 수정·삭제는 **임시 파일에 다 쓴 뒤 한 번에 교체**해요(원자적 저장). 중간에 실패해도 원본이 안전해요.

```
[완료] export.csv (5 records)
```

## 11. 오류 메시지 + 종료 코드 — [요구 4.14]

`echo $?`는 **방금 실행한 명령의 종료 코드**를 보여줘요. (0 = 정상, 0이 아니면 오류)

- [ ] 잘못된 값 → 종료 코드 1

```bash
python3 -m budget_app summary --month 2024-13
echo $?
```

**예상 결과**
```
[오류] 월 형식이 올바르지 않습니다 (YYYY-MM).
[힌트] 예: 2024-01
1
```

- [ ] 필수 옵션 빠뜨림 → 종료 코드 2

```bash
python3 -m budget_app summary
echo $?
```

**예상 결과**
```
[오류] 명령 형식이 올바르지 않습니다 — the following arguments are required: --month
[힌트] python -m budget_app summary --help 로 사용 방법을 확인하세요.
2
```

> 포인트: 어떤 오류에서도 **스택트레이스(Traceback)가 나오지 않고**, "원인 + 해결 힌트"만 보여줘요.

## 12. 재실행 후 데이터 유지 + 저장 파일 + 실행 로그 — [요구 4.4, 4.13]

- [ ] 터미널을 닫고(휴지통 아이콘) **새 터미널**을 연 뒤 목록 보기

```bash
python3 -m budget_app list --limit 3
```

**예상 결과**: 앞에서 넣은 거래가 그대로 보여요. → 프로그램을 껐다 켜도 **데이터가 유지**돼요.

- [ ] 저장 파일 확인

```bash
ls data
```

**예상 결과**
```
app.log
budgets.jsonl
categories.jsonl
recurring.jsonl
transactions.jsonl
```

> 포인트: 거래 / 카테고리 / 예산이 **각각 다른 파일**에 저장돼요 (3개 이상). `head -2 data/transactions.jsonl`로 보면 **한 줄 = 거래 1건** (JSONL)이에요.

- [ ] 데코레이터가 남긴 실행 로그 확인

```bash
tail -3 data/app.log
```

**예상 결과** (시간은 다름)
```
2026-10-10 19:05:16,838 command=cmd_export exit_code=0 elapsed=0.001s
2026-10-10 19:05:16,910 command=cmd_summary exit_code=1 elapsed=0.000s
2026-10-10 19:06:02,120 command=cmd_list exit_code=0 elapsed=0.000s
```

> 포인트: 명령 함수에 붙인 `@log_execution` 데코레이터가 **명령 이름 · 종료 코드 · 걸린 시간**을 자동으로 기록해요.
